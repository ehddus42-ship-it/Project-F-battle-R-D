# 리미널 전투 랩 (Liminal Combat Lab)

브라우저에서 바로 플레이하며 이동 속도와 전투 감각을 튜닝하는 2D 프로토타입이다.

**플레이:** https://ehddus42-ship-it.github.io/Project-F-battle-R-D/

## 조작
| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 / J | 공격 (누르고 있으면 6타 콤보) |
| Space / Shift / 우클릭 | 대시 (적 공격 직전이면 저스트 회피) |
| R / H / P | 방 리셋 / 판정 보기 / 일시정지 |

## 피드백 보내는 법
1. 오른쪽 패널에서 수치를 조정한다. 바뀐 값에는 •가 붙고 브라우저에 저장된다.
2. **값 JSON 복사**를 눌러 바뀐 값만 복사한다.
3. 이슈나 메신저로 JSON과 느낀 점을 공유한다. 받은 값은 **JSON 붙여넣기**로 그대로 재현할 수 있다.

기본값은 Unity 프로젝트의 플레이어·몬스터 스크립트 수치와 같다.

## 보간 곡선 (그래프로 R&D)
오른쪽 패널 맨 위 **보간 곡선 · 그래프**에서 전투 감각을 결정하는 보간 값을 곡선으로 직접 편집한다.

| 곡선 | 가로 (0→1) | 세로 |
|---|---|---|
| 이동 가속 / 이동 감속 | 가속·정지 진행 | 속도 비율 |
| 대시 / 돌진 속도 프로필 | 대시·돌진 진행 | 속도 배율 (총 거리·도착 지점은 유지) |
| 히트 스톱 / 저스트 회피 슬로 복귀 | 스톱·슬로 진행 | 0 = 스톱 속도, 1 = 정상 속도 |
| 적 넉백 감속 | 넉백 진행 | 속도 비율 |
| 화면 흔들림 감쇠 | 흔들림 진행 | 진폭 배율 |

- 빈 곳 클릭으로 점 추가, 드래그로 이동(Shift는 0.05 스냅), 더블클릭·우클릭으로 삭제한다.
- **부드럽게 / 직선**으로 보간 방식을 바꾸고, 프리셋(Ease In/Out, S 커브, 오버슈트, 초반 폭발 등)에서 시작할 수 있다.
- 점선은 Unity 기본 곡선, 보라 선은 지금 게임이 곡선의 어디를 읽고 있는지 보여준다.
- 아래 **플레이어 속도 / 시간 배율** 그래프로 최근 3초의 실제 결과를 확인한다.
- **Unity C# 복사**는 같은 모양의 `AnimationCurve` 필드 코드를, **값 JSON 복사**는 수치와 곡선을 함께 복사한다.

## 대시 추천 곡선 (기본값)
`(0, 1.40) · (0.30, 1.35) · (0.75, 0.60) · (1, 0.315)`, 부드럽게. 대시 13 m/s · 0.19 s 기준:

| 항목 | Unity 원본 (일정) | 추천 |
|---|---|---|
| 시작 속도 | 13.0 m/s | 18.5 m/s |
| 첫 프레임 이동 (60fps) | 22 cm | 31 cm |
| 거리 절반 도달 | 95 ms | 68 ms |
| 끝 속도 | 13.0 m/s (→ 4.2로 급락) | 4.2 m/s (= 이동 속도, 이음매 없음) |
| 총 거리 · 무적 시간 | 2.47 m · 0.19 s | 동일 |

프리셋의 **Unity 원본 (일정)**으로 바로 비교할 수 있다.
